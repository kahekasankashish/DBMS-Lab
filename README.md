# DBMS Lab — PostgreSQL

A collection of Database Management Systems (DBMS) lab assignments completed as part of the B.Tech Computer Science and Engineering coursework at Silicon University.

The repository contains SQL and PL/pgSQL source files for the assignments.

## Repository Structure

| Folder                         | Assignment                                    | Topics covered                                                              |
| ------------------------------ | --------------------------------------------- | --------------------------------------------------------------------------- |
| `01_Table_Creation_and_Alteration`             | Assignment 1 — Create Tables                  | Table creation, table structure, altering tables and inserting records      |
| `02_Simple_SQL`                | Assignment 2 — Simple SQL                     | Basic SELECT queries, filtering, sorting and joins                          |
| `03_Operators_Comparison_Like` | Assignment 3 — Operators, Comparison and LIKE | SQL operators, comparison conditions and pattern matching                   |
| `04_Single_Row_Functions`      | Assignment 4 — Single Row Functions           | String, numeric, date and conversion functions                              |
| `05_Aggregate_Functions`       | Assignment 5 — Aggregate Functions            | Aggregate functions, grouping and filtering grouped results                 |
| `06_Nested_Queries`            | Assignment 6 — Nested Queries                 | Subqueries and nested SELECT statements                                     |
| `07_DDL_Statements`            | Assignment 7 — DDL Statements                 | CREATE, ALTER, DROP and other data definition operations                    |
| `08_Constraints`               | Assignment 8 — Constraints                    | Primary keys, foreign keys, unique, check, default and not-null constraints |
| `09_Update_Exercise`           | Assignment 9 — Update Exercise                | UPDATE and DELETE operations                                                |
| `10_DML_Statements`            | Assignment 10 — DML Statements                | INSERT, UPDATE, DELETE and SELECT operations                                |
| `11_Join_Operation`            | Assignment 11 — Join Operation                | Joins across employee, department, project and related tables               |
| `12_Views`                     | Assignment 12 — Views                         | Creating and querying views, view-based insert and update operations        |
| `13_Sequences`                 | Assignment 13 — Sequences                     | Creating, altering and using sequences                                      |
| `14_Indexes`                   | Assignment 14 — Index                         | Creating and managing indexes; PostgreSQL index limitations                 |
| `15_Set_Operations`            | Assignment 15 — Set Operations                | UNION, UNION ALL, INTERSECT and EXCEPT                                      |
| `16_Transactions`              | Assignment 16 — Transactions                  | Savepoints, rollback, commit and read-only transactions                     |
| `17_PLSQL_Blocks_Conditions`   | Assignment 17 — PL/SQL Blocks and Conditions  | Procedural blocks, variables, conditions, loops and exception handling      |
| `18_PLSQL_Stored_Procedures`   | Assignment 18 — PL/SQL Stored Procedures      | Creating and calling stored procedures                                      |
| `19_PLSQL_Functions`           | Assignment 19 — PL/SQL Functions              | User-defined functions, calculations and returning query results            |
| `20_Cursors`                   | Assignment 20 — Cursors                       | Explicit cursors, fetching records, row counts and cursor-based processing  |
| `21_Exception_Handling`        | Assignment 21 — Exception Handling            | Built-in and custom exception handling in procedural SQL                    |

## Technology

- **Database:** PostgreSQL
- **Query language:** SQL
- **Procedural language:** PL/pgSQL
- **Tools:** PostgreSQL-compatible SQL client (for example, pgAdmin or `psql`)
